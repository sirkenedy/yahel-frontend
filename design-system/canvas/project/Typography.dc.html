Eleven roles, two size classes

Roles follow the iOS text styles so native and web share one vocabulary. Touch sizes match iOS at the default Dynamic Type setting. Pointer sizes are denser for desktop work.

Scales with the reader
Sizes are tokens in rem. Dynamic Type on iOS and browser zoom on web resize every role together, and layouts reflow.
Tracking tightens as size grows
Titles from 20 px up tighten slightly. Body stays at zero. All-caps labels open up. Each role carries its own value.
Hierarchy by weight, then size
Headline and Body share a size and differ by weight. Colour is the last tool for emphasis, never the first.
