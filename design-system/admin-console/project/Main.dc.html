yaheladminv1

Where business admins land after sign-up.

A separate app on its own subdomain. Version 1 covers domain setup (verify, mail, protection), the console home, and users. Everything else is a clearly marked placeholder. Built from the Yahel Design System, in Yahel’s own look.

In this file

  • 1 Clickable prototype: own domain, bought domain, console
  • 2 Setup flow: 21 screens, light and dark
  • 3 Console: Home; Users with units, filters, bulk actions, add people, download and custom profile fields; account menu; full side menu; placeholders for every other module
  • Web boards are 1440 wide. Phone versions (390 wide) of every screen are on pages 4 and 5.

Decisions

  • Setup runs full screen, outside the console, like Google’s order of steps
  • Verify by connecting to the host or adding a record. No screen sharing, no host passwords
  • Domains bought with Yahel set themselves up
  • List existing addresses before switching mail so nothing bounces
  • SPF, DKIM and DMARC together, DMARC starting in watch-only mode

Open

  • Which hosts support automatic connection (only GoDaddy and Cloudflare are marked)
  • The final list of Nigerian registrars
  • Mail and DNS hostnames (mx1.yahel.com and so on are placeholders)
  • Billing waits for Phase 4
