# Writing

Words are interface. These rules apply to every label, message and email the product sends.

## Voice

Clear, calm, respectful. We sound like a capable colleague: direct, never cute, never alarmed. Tone shifts with the moment (lighter on a welcome screen, exact in a security prompt), the voice does not.

## Rules

| Rule | Do | Don't |
|---|---|---|
| Lead with the action | "Share", "Get more storage" | "Click here", "Submit" |
| Sentence case everywhere | "Add another account" | "Add Another Account" |
| Name the thing, not the system | "Can't send. Check your connection." | "Error 503: SMTP relay failure" |
| No blame, no drama | "That password is too short. Use at least 12 characters." | "Oops! Invalid password!" |
| Avoid "we" and sparing "your" | "Unable to load files" | "We're having trouble loading your files" |
| Say what happens | "Delete forever" | "OK" |
| Be specific about people | "People in Northwind Studio will lose access" | "Others may be affected" |
| Device-neutral verbs | "Select", "Choose", "Open" | "Click", "Tap" in shared copy |
| Numbers as numerals with units | "3 files", "2 GB left" | "three files" |

## By element

- **Buttons.** A verb, one to three words. The confirming button repeats the action from the title: "Remove from shared drive?" then "Remove".
- **Titles.** Name the task or place. Dialog titles for risky actions are questions.
- **Multi-step flows.** "Continue" between steps, "Done" at the end, used the same way everywhere.
- **Errors.** Next to the problem. What happened, then how to fix it. If nothing can be done, say when to try again.
- **Empty states.** One line on what belongs here, one action to add it.
- **Permissions and sharing.** Plain summaries of who can do what: "Only invited people can edit", "Anyone at Northwind Studio with the link can view".
- **Settings.** The label describes what happens when it is on. Link straight to a setting instead of describing where it is.
- **Fields.** Always a visible label. Placeholder text is an example, never the label.
- **Notifications.** Who, what, where: "Lena shared 'Brand refresh' with you".
- **Upgrade and limits.** Facts and a path: "2 GB left. Get more storage." Never fear or false urgency.

## Vocabulary

One word per concept across all apps. Start of the shared list:

| Use | Not |
|---|---|
| Sign in, sign out | Log in, log out |
| Personal account, organisation | Private account, company, workspace, tenant |
| Share, people with access | Collaborators, ACL |
| Trash | Bin, deleted items |
| Storage | Space, quota |
| Organisation (British spelling in en-GB; "organization" in en-US) | Mixed spelling in one locale |

## Localisation

Write so it translates: full sentences, no concatenated fragments, no idioms, placeholders for names and numbers, room for text to grow by half. See `inclusion-and-localization.md`.
