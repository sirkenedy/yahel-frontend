# Search

Finding things is a primary task in every app, so search has a primary position.

## Rules

- **One field, one place.** Centre of the top bar on wide layouts; the trailing tab or the top of the root view on compact. A single shortcut (`/`, and Command or Control K) focuses it from anywhere.
- **Scope is always stated.** The placeholder names it: "Search mail", "Search Northwind Studio". In-app search covers that app; the suite launcher searches everything the person can access.
- **Context is respected.** Results come only from the current account context unless the person widens the scope, and each result shows which context and app it belongs to.
- **Before typing:** recent searches and useful suggestions. Recent searches can be cleared, individually and all at once.
- **While typing:** results update live, with the matched text emphasised by weight, not colour alone. People, files and messages are grouped with a count.
- **Filters** appear as removable tokens in the field and as a filter row under it: type, owner, date, has attachment, shared with.
- **Results** open the exact item at the match; Back returns to the same results and scroll position.
- **No results** says so plainly and offers a fix: check spelling, remove a filter, search another context.
- **Speed:** the first results within a second; show partial results rather than wait for all.
- **Privacy:** never show results the person cannot open. Search history stays on the account and is not visible to administrators as a browsing record unless organisation policy says so, in which case the person is told.

## Keyboard

Arrow keys move through suggestions and results, Enter opens, Escape clears then closes.
