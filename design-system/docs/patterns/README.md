# Patterns

Patterns are the rules for common tasks that span components and apps. A component spec says how a sheet looks; a pattern says when to use one.

| Pattern | File | Covers |
|---|---|---|
| Navigation | `navigation.md` | Launching, moving between apps and views, windows, full screen |
| Onboarding and accounts | `onboarding-and-accounts.md` | First run, sign-in, personal and organisation context, account deletion |
| Feedback and status | `feedback-and-status.md` | Feedback, loading, empty, errors, offline, notifications, undo, haptics |
| Search | `search.md` | Suite-wide and in-app search |
| Sharing and collaboration | `sharing-and-collaboration.md` | Sharing, permissions, presence, comments, external people |
| Entering data | `entering-data.md` | Forms, validation, defaults, pickers |
| Modality | `modality.md` | Dialogs, sheets, popovers, menus |
| Files and storage | `files-and-storage.md` | File management, drag and drop, upload, trash, printing and export |
| Plans and upgrades | `plans-and-upgrades.md` | Free personal tier, storage limits, upgrade flow |
| Settings and help | `settings-and-help.md` | Settings, help, feedback requests |
| AI assistance | `ai-assistance.md` | Any generated or suggested content |
| Composing | `composing.md` | Mail and Chat: recipients, drafts, attachments, send and undo send |
| Scheduling | `scheduling.md` | Calendar: events, recurrence, availability, time zones, invitations |
| Audio and video | `audio-and-video.md` | Meet calls, voice messages, media preview |
| Admin and bulk actions | `admin-and-bulk-actions.md` | Admin console tables, bulk actions, roles, audit |
| Email and documents | `email-and-documents.md` | Transactional email, exported PDFs, printing |

Charting data is covered by `../foundations/data-visualisation.md` and `../components/chart.md`. Platform differences are in `../platforms.md`.
